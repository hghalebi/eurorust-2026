## Projects and professional work

- [cogenitor](https://github.com/upachler/cogenitor). An OpenAPI code generator for Rust, listed on the speaker's GitHub profile. [Attribution](https://github.com/upachler).
- [ebur128_compressor](https://github.com/upachler/ebur128_compressor). A Rust LV2 audio-compressor project using EBU R128 loudness concepts. [Attribution](https://github.com/upachler).
- [mwbmodel](https://github.com/gentity/mwbmodel). A Java library for reading MySQL Workbench files. The published package metadata credits Pachler as a developer. [Attribution](https://central.sonatype.com/artifact/com.github.upachler.mwbmodel/mwbmodel).
- [Matter and ESP32 integration report](https://github.com/sysgrok/rs-matter-embassy/issues/33). An issue and follow-up by Pachler documenting integration with an IKEA controller. This is a user contribution to rs-matter-embassy, not authorship of that library.
