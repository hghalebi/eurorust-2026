## Projects and professional work

- [hotpath-rs](https://github.com/pawurb/hotpath-rs). A Rust profiler covering instrumented execution, CPU, memory, and asynchronous workloads. Consult the current documentation for supported versions and overhead. [Attribution](https://pawelurbanek.com/).
- [rails-pg-extras](https://github.com/pawurb/rails-pg-extras). PostgreSQL diagnostics for Rails, useful context for the author's approach to application performance. [Attribution](https://pawelurbanek.com/).
