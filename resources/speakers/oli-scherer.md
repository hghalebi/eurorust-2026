# Oli Scherer

Rust compiler internals, compile-time evaluation, and Miri's checks for undefined behavior.

At EuroRust 2026:

- [Move your problems to compile-time and get new capabilities out of it](https://eurorust.eu/talks/move-your-problems/)

Follow the official page for the current session description and access details.

## Articles and research

- [Miri: Practical Undefined Behavior Detection for Rust](https://plf.inf.ethz.ch/research/popl26-miri.html) (Research paper). Coauthored research published at POPL 2026, explaining the tool's design, coverage, and evaluation. Useful background before relying on Miri in a validation workflow.

## Talks and teaching

- [Pattern types — RustWeek 2025](https://2025.rustweek.org/talks/oli/). A compiler-oriented talk about adding pattern types to Rust.
- [Reliable optimizations for idiomatic Rust](https://hackmd.io/@oli-obk/ryhIVhKkv). Speaker-hosted slides linked from an OxidizeConf 2020 presentation note; background on MIR optimization and compile-time evaluation. [Attribution](https://hackmd.io/@oli-obk/BJ0Rhjt1P).

## Projects and professional work

- [Miri](https://github.com/rust-lang/miri). An interpreter used to detect undefined behavior in executed Rust code. The Rust directory lists Scherer as a Miri lead; this is a collaborative project. [Attribution](https://rust-lang.org/governance/people/oli-obk/).
- [Rust reflection and compile-time evaluation goal](https://goals.rust-lang.org/2026/reflection-and-comptime.html). The accepted 2026–2028 project goal names Scherer as a contact. It describes planned language work, not a promise of features available in stable Rust.
