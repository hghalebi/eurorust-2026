# Jake Lishman

Quantum compilers, Python–Rust integration, and numerical software.

EuroRust sessions (check official pages for details and access):

- [Moving a quantum compiler from Python to Rust](https://eurorust.eu/talks/moving-a-quantum-compiler-from-python-to-rust/)

## Articles and research

- [LightSABRE: A Lightweight and Enhanced SABRE Algorithm](https://arxiv.org/abs/2409.08368) (Preprint). Coauthored preprint on quantum-circuit routing implemented primarily in Rust within Qiskit. Performance claims belong to the paper's stated benchmarks.
- [Trapped-Ion Entangling Gates Robust Against Qubit Frequency Errors](https://arxiv.org/abs/2004.07253) (Research paper). Coauthored quantum-physics research, listed in his own publication bibliography. [Attribution](https://binhbar.com/about/).

## Projects and professional work

- [Qiskit](https://github.com/Qiskit/qiskit). Quantum-computing SDK; Lishman's profile identifies him as technical lead. Relevant background for the conference's Python-to-Rust migration talk. [Attribution](https://github.com/jakelishman).
- [qiskit-qasm2](https://github.com/jakelishman/qiskit-qasm2). OpenQASM 2 parser combining Python and Rust; package documentation explains the lexer design. [Attribution](https://pypi.org/project/qiskit-qasm2/0.3.2/).
