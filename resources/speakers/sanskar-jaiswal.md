# Sanskar Jaiswal

Streaming proxies, Kubernetes networking, and progressive delivery with Flux and Flagger.

EuroRust sessions (check official pages for details and access):

- [Designing State Machines for Streaming Proxies in Rust](https://eurorust.eu/talks/designing-state-machines-for-streaming-proxies-in-rust/)

## Talks and teaching

- [KubeCon and PromCon speaking archive](https://sanskarjaiswal.net/talks/). Slides and recordings cover Gateway API integration, SLO validation, OCI/Cosign with Flux, and the Flux ecosystem, from 2022–2025.

## Projects and professional work

- [Flagger](https://github.com/fluxcd/flagger). A Kubernetes progressive-delivery operator. The Flux project announced Jaiswal as a maintainer in 2022 and credited Gateway API support. [Attribution](https://fluxcd.io/blog/2022/06/may-update/).
- [Flux](https://github.com/fluxcd/flux2). The GitOps project named in the EuroRust biography. This is shared project work, not a personal library. [Attribution](https://eurorust.eu/talks/designing-state-machines-for-streaming-proxies-in-rust/).
- [Rust DNS resolver](https://github.com/aryan9600/dns-resolver). A small learning project explicitly described by the author as a toy resolver. [Attribution](https://github.com/aryan9600).
