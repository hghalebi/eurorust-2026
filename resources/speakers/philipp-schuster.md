# Philipp Schuster

Virtual machines, Rust operating-system tooling, and reproducible infrastructure with Nix.

At EuroRust 2026:

- [Inside Cloud Hypervisor: From KVM to a Running VM](https://eurorust.eu/talks/inside-cloud-hypervisor-from-kvm-to-a-running-vm/)

Follow the official page for the current session description and access details.

## Articles and research

- [Booting a minimal Linux guest](https://phip1611.de/blog/quickly-boot-a-minimal-linux-kernel-initrd-in-cloud-hypervisor-or-qemu/) (Article). A technical article preparing kernel and initrd inputs for Cloud Hypervisor or QEMU. [Attribution](https://phip1611.de/).

## Talks and teaching

- [Writing an OS loader with uefi-rs](https://jugsaxony.org/downloads/events/slides/20251106_OS-Loader-in-Rust-schreiben-mit-uefi-rs.pdf). Slides from JUG Saxony, November 2025, connecting Rust abstractions to firmware and bootloaders.

## Projects and professional work

- [Cloud Hypervisor](https://github.com/cloud-hypervisor/cloud-hypervisor). The collaborative Rust virtual machine monitor discussed in the EuroRust session. Release notes independently credit Schuster's contributions. [Attribution](https://www.cloudhypervisor.org/blog/cloud-hypervisor-v51.0-released/).
- [uefi-rs](https://github.com/rust-osdev/uefi-rs). Rust interfaces for UEFI; Schuster identifies it among the projects he maintains. [Attribution](https://de.linkedin.com/in/phip1611).
- [Public Nix and NixOS configurations](https://github.com/phip1611/nixos-configs). Reusable modules, packages, and system configurations. Read the current flake requirements before adapting them. [Attribution](https://github.com/phip1611).
- [Diplom thesis implementation](https://github.com/phip1611/diplomarbeit-impl). An archived research implementation from TU Dresden involving the Hedron microhypervisor. This is a thesis artifact, not a maintained production system. [Attribution](https://github.com/phip1611).
