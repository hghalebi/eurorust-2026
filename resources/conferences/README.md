## Read the coverage labels

- **Indexed:** all entries in the stated programme scope are captured. Recordings may still be missing.
- **Partial:** useful session records exist, with named gaps.
- **Source links:** an edition is located; its sessions are not yet indexed.
- **Access gap:** a source could not be retrieved.

Future sessions are announcements. A recording link does not establish playback, and a passed date does not prove a talk happened. Source languages and original titles are preserved; translations are attributed to the organizer.

## Help fill a gap

[Send a correction](../../CONTRIBUTING.md) with an official programme, speaker page, recording, slides or code link. Include the edition and date; the same talk can appear at several conferences. Original materials keep their own rights.

This source-checked draft has not been reviewed by every organizer or speaker. It does not claim a complete world archive. The [coverage ledger](../../community/conference-archive/coverage.json) records regional searches, omissions and access limits.
