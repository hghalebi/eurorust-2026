## Use the calendar

Download [events.ics](events.ics) and import it into a separate calendar.
It contains announced or ongoing event dates from the [discovery directory](../../community/rust-discovery.json)
and open calls with verified deadlines. Event dates are all-day spans; they are not
session timetables. Exact deadlines use UTC in the file and retain the organizer's
timezone in their description. A date-only deadline is a reminder with an unknown cutoff time.

This is a downloadable snapshot, with no automatic refresh. Replace the imported
calendar when updating; a later import may leave old entries behind. Unknown dates,
tentative events, closed calls, and unverified recurring meetings are excluded.
No alarms, registrations, or subscriptions are created by this repository.

Unless stated, costs, spoken language, captions, equipment, venue, room, and eligibility
are unknown. Follow each event link for its date and location; a submission deadline
is separate from the event it concerns.
