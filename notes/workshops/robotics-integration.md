# Preparing for autonomous-system integration

Status: source-based preparation, not attendance or registration. Session ID:
`workshops-rust-on-the-field-integrating-real-autonomous-systems`. Source:
[official workshop](https://eurorust.eu/workshops/rust-on-the-field-integrating-real-autonomous-systems/).

The workshop describes Rust connectors for heterogeneous systems and unreliable
transport. Its stated prerequisite is comfort with async Rust and Tokio; previous
robotics/protocol experience is not required. The page describes provided hardware
and emailed laptop setup instructions. Confirm access and current logistics.

For this conference path, focus questions on timeouts, retries, stale observations,
shared data models, and observable failure. Avoid assuming that local type safety
establishes the state of a physical system. A simulated exercise is distinct from
physical-system validation.

Alternative robotics workshops differ: the line-follower exercises use simulation,
while the embedded workshop describes supplied Pico-based hardware and USB setup.
Choose based on goals, prerequisites, bookings, and availability.
