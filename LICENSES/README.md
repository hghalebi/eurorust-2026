# Reuse the work with attribution

Original prose, summaries, community annotations, and original example learning
paths use [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
Attribute this repository and the named contributor, link the license, and
identify your changes. The linked license contains the full terms.

Software and code examples use [the MIT license](../LICENSE).

Official conference facts and third-party material retain applicable upstream
rights and terms. These licenses grant no rights in conference branding, speaker
slides, photographs, transcripts, or source pages. Retain source URLs and
attribution when reusing context. See the [source and reuse policy](../docs/source-and-reuse-policy.md)
for publication boundaries.
