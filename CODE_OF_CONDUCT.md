# Community code of conduct

Treat participants with respect across experience levels. Discuss ideas and
evidence constructively. Personal attacks, harassment, discrimination, and
unwanted contact are unacceptable. Respect consent and privacy.

Maintainers may remove harmful content and restrict participation. To report a
repository concern, use an available private maintainer contact or GitHub
reporting option where possible. Keep sensitive details out of public issues.

For an incident at EuroRust, follow the official
[conference code of conduct](https://eurorust.eu/code-of-conduct/) and organizer
reporting channels. This repository does not operate conference incident response.
