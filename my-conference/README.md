# My EuroRust path

This repository starts with planning a useful conference experience, then makes
the same resources reusable by fellow attendees and their agents.

The public example explores production reliability, Rust type systems,
infrastructure, and robotics. It is a **proposed learning path**, not a record of
attendance or confirmed registration. Session ideas are engineering foundations
for reliable tools and workers; they are not a promise of an autonomous-agent
framework tutorial.

Read the [proposed itinerary](itinerary.md), its [checked JSON](itinerary.json),
and the [shareable goals profile](profile.json). The public profile records only
learning themes; availability and attendance mode are unknown and no workshop
registration is recorded. Reproduce both views with:

```sh
bin/conference-data recommend --profile my-conference/profile.json --output my-conference/itinerary.json --markdown my-conference/itinerary.md
```

 Use the official
[schedule](https://eurorust.eu/schedule/) to confirm current times and access.

Personal logistics stay outside the published examples. Other participants
should choose their own path from their goals and constraints.

For my follow-up, October 17 impl Day is a conditional opportunity to test a
small tool or worker contract and its failure behavior. Confirm participation
and prepare the environment before treating this as a commitment.
