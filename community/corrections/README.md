# Spotted a detail that could change someone's plan?

[Report a data correction](https://github.com/hghalebi/eurorust-2026/issues/new?template=data-correction.yml).
Include the session name or official URL, the detail that looks wrong, when you
checked it, and the correction you propose. Add the session ID and snapshot
(recorded dataset version) if you have them. A clear report with a source is
enough to start; maintainers can find the relevant data record.

If two sources disagree, show both values and explain the difference. That gives
maintainers enough evidence to check the source, fix extraction where needed,
and regenerate the data. Corrections belong in the source or annotation route;
hand-edited generated views are replaced by the next export.

See [where to contribute](../../CONTRIBUTING.md#where-to-contribute) for the owning
files and checks.
