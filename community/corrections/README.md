# Report a correction

[Open a data correction](https://github.com/hghalebi/eurorust-2026/issues/new?template=data-correction.yml)
with the session name or official URL, proposed correction, source, and checked
date. Add the session ID and snapshot if known.

If sources disagree, include both values. Maintainers can check the evidence,
correct the source or extraction, and regenerate the data. Manual edits to
generated exports will be replaced.
