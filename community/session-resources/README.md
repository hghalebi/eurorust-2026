# Curated session resources

Read the [session pages](../../resources/related-talks/README.md) or
[learning guide](../../docs/learning-resources.md).

Each JSON file owns one EuroRust talk or workshop's recommendations.
Its filename matches `session_id`. Keep specific reasons, source evidence,
author attribution, access, dates, and announcement status with each resource.
The [schema](../../schema/session-resources.schema.json) describes the format.

Use the [source manifest](../learning-manifest.json) for the reviewed catalog
join. The compiled helper checks inputs and generates public views; it does not
search the web or certify editorial quality.

[Suggest a source or correction](../../CONTRIBUTING.md#learning-resources-and-archives).
